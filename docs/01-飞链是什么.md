# 飞链是什么

飞链（FeiLian RAG）是一个本地优先的检索增强生成工具。它把散落在文件夹里的文档读进向量库，
让大模型在回答问题时只依据你自己的资料，并且把每一句结论的来源标出来。

## 名字的由来

「链」有两层意思。第一层是检索链：加载 → 切块 → 向量化 → 召回 → 生成，每一步都能单独替换。
第二层是证据链：答案里的每个 [1]、[2] 都能点回到具体文件、具体页码、具体段落，用户可以自己核。

## 三个设计取舍

1. 本地优先。默认用 Ollama 跑本地模型，文档不出机器；需要更强效果时再切到 OpenAI。
2. 索引可增量。每次同步只处理内容和指纹发生变化的文件，不再全量重建。
3. 宁可说不知道。资料里没有答案时明确回答「没有找到」，而不是顺着问题编一段。

## 适合什么场景

- 个人知识库问答：自己的笔记、收藏、剪藏
- 团队文档检索：接口文档、规范、会议纪要
- 长文档精读：年报、标准、论文，按页定位

## 不适合什么场景

- 需要实时联网检索最新资讯（这里只查本地文档）
- 需要精确计算的场景（向量检索不擅长数值推理）
- 千万级文档的大规模检索（这是单机工具，不是搜索引擎）
